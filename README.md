# Application Development Activity Portfolio

## Updated Project Structure

Assets have been reorganized under an `assets` folder:

- `assets/css/` — All CSS files (content.css, navigation.css, styles.css)
- `assets/js/` — All JavaScript files (index.js, script.js)
- `assets/img/` — Images and icons (PNG files)
- `assets/docs/` — Documents (resum.pdf)

HTML files (`index.html`, `portfolio.html`) have been updated to reference these new locations.

## How to run

Open `index.html` or `portfolio.html` in your browser. No build step required.
